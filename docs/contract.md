# Stratified SRS estimation v1

本项目为抽样分析人员把完整分层人口规模与实际样本转成设计权重、总体均值和抽样不确定度。
输入 strata(id,population 正整数<=10^9)、sample(unit_id,stratum,value)。
unit_id全样本唯一；每层至少抽到一个、至多population个单位，层ID与引用须匹配。
value 必须是有限十进制文本，绝对值<=10^9、最多6位小数，允许负数和0；缺失不当0，直接拒绝。
输入最多100000条。无样本的正人口层不能计算总体，拒绝而非悄悄删除。

假定各层独立简单随机无放回抽样（SRSWOR），层内等概率，所有样本响应。
不自动判断采样方案真伪、不校正非响应、不支持多阶段/整群/PPS/校准权重或比例估计。
Nh层人口、nh样本、yh样本均值、s²h无偏样本方差：
总量=sum(Nh*yh)，总体均值=总量/sum(Nh)，每单位设计权重=Nh/nh。
总量方差=sum(Nh²*(1-nh/Nh)*s²h/nh)，均值方差=总量方差/N²。
若nh=Nh则该层方差贡献0，即使Nh=nh=1。若nh=1且非普查，方差无法估计，
总体variance_mean和standard_error_mean为null，明确列出缺失层，不把它猜为0。

Fraction对十进制输入和统计量执行精确计算，JSON numerator/denominator均为文本。
仅标准误平方根输出近似float。输出逐层估计和逐单位权重，可追溯总体估计来源。
不输出正态置信区间或显著性判断；小样本方差不代表样本具有代表性。
样例N=10，样本5，估计总量192、均值19.2、均值方差1.28、标准误约1.13137085。
未经加权的样本均值19.2在本例恰好一致（两层抽样率都1/2），测试另含不等抽样率。

当前全量内存计算，没有真实个人信息、交互图表或多波次追踪。问卷修订记录由
独立的导入步骤（见下文 `survey-import`）归并为上述输入，估计器本身不读取修订 CSV。

## 可重叠子总体（`--domains`，v1 可选扩展）

`--domains` 接受独立 JSON 文件，顶层必须是对象：域名 -> unit_id 字符串数组。
域名遵循上文文本约束（非空、<=256 字符、无控制字符）；`{}` 与空数组合法。
同一 unit_id 可出现在多个域（重叠），也可不出现在任何域；域内重复或引用样本外
unit_id 一律拒绝。成员文件错误（非法 JSON、非对象根、重复键、非数组、坏域名、
坏成员、未知单位）与计算失败一样退出 2，且不触碰既有输出。
未传 `--domains` 时报告不含 `domains` 键，逐字节与旧版一致。

传入时报告新增按域名（文本序）排序的 `domains` 数组，每项字段：
`domain`、`estimated_count`、`estimated_total`、`estimated_mean`、`variance_mean`、
`standard_error_mean`、`variance_unavailable_strata`。除标准误为 float 外，其余连续量
继续用精确分数 numerator/denominator 文本。

设域成员指示量 x_ui=1（样本单位属于域）或 0，设计权重 w_hi=Nh/nh：
估计人数=sum(w_hi*x_ui)，域总量=sum(w_hi*x_ui*y_ui)，域均值R=域总量/估计人数。
均值方差用比率线性化：线性化变量 z_ui=(y_ui-R)*x_ui/估计人数（非成员z=0；设计权重
只经由层方差公式进入，不重复乘入z），逐层 s²z=sum(z-zbar)²/(nh-1)，
域均值方差=sum(Nh²*(1-nh/Nh)*s²z/nh)。
必须保留全部样本单位参与逐层均值与方差，不能先筛选成员再按成员重算抽样率。
若nh=Nh该层贡献0；若nh=1且非普查，域variance_mean与standard_error_mean为null，
并在 `variance_unavailable_strata` 按层ID排序列出缺失层；域外观测贡献零但仍占 nh。
估计人数为 0（空域或成员全部未抽样）时域总量为 0，估计均值、均值方差、标准误均为
null，不伪造 0 中心。全体样本单位构成一个域时，其结果与总体估计逐项精确相等。
域间可重叠，故各域估计不可相加还原总体。

样例 `fixtures/domains.json`：`all` 含全部 5 个样本单位（复现总体：人数10、总量192、
均值19.2、均值方差1.28、标准误约1.13137085）；`youth`=S1+L1 跨两层重叠示例
（人数4、总量60、均值15、均值方差25/4、标准误2.5）；`none` 为空域（均值族为null）。

## 问卷修订导入（`survey-import`，v1 前置步骤）

`survey-import --manifest <清单JSON> --output <样本JSON>` 把问卷修订 CSV 归并为
与本项目 `--source` 同口径的样本文件。仅依赖标准库，不联网。

清单顶层必须只有 `strata` 与 `files` 两个键。`strata` 与原输入逐项一致：
每项仅含 `id`(文本) 与 `population`(1..10^9 整数)，层 ID 不重复；
清单没有层时，任何 upsert 都会因未知层被拒绝。`files` 为数组，每项仅含：

- `path`：相对清单所在目录的路径，遵循文本约束（非空、<=256 字符、无控制字符）；
- `sha256`：原文件内容的 64 位十六进制 SHA-256（大小写不敏感）。

每个 `path` 必须是清单目录内的普通文件：拒绝绝对路径、含 `..` 的路径、解析后
越出清单目录的路径、符号链接、目录、缺失或不可读的文件。清单与每个修订文件各自
上限 8 MB，清单还沿用输入的重复 JSON 键检查；清单本身错误同样退出 2，
报错给出清单路径与 `files` 下标（能识别时附相对路径）。

CSV 文件按字节读取并校验哈希后才解析；任何哈希不符立即拒绝，报错含相对路径、
期望与实际摘要，因此不能靠事后替换内容绕过校验。文本必须是 UTF-8（含 BOM 拒绝），
首行表头严格等于 `unit_id,revision,op,stratum,value`（顺序、拼写、大小写均不可变），
重复表头行按记录拒绝。空白行忽略，不计入记录号；其余每行必须恰好 5 列
（不允许多余或缺失列），按记录号（表头后的第 1 条数据起）与物理行号定位错误。

- `unit_id`：文本约束同原输入（非空、<=256 字符、无控制字符）。
- `revision`：正整数的十进制文本（仅 ASCII 数字，不接受符号、空白、小数点或 0）；
  前导零按数值归一，比较按数值而非字典序（`10` 高于 `9`），不是近似版本号。
- `op`：仅 `upsert` 或 `delete`。
- `upsert`：`stratum` 必须非空且出现在清单 `strata` 中，否则按未知层拒绝；
  `value` 沿用原输入的十进制文本约束（有限、|值|<=10^9、最多 6 位小数、允许负数和 0），
  缺失不当 0，坏值直接拒绝。输出保留 `value` 原始文本，不重写数值；因此
  `10` 与 `10.0` 视为不同文本，同版本并存即冲突。
- `delete`：`stratum` 与 `value` 必须都为空，非空即拒绝。

逐条校验全部记录后才归并；任何记录出错（包括只出现在低版本、最终不采用的数据）
都会使整个导入失败，不静默跳过。归并规则按 `(unit_id, revision)`：

- 同一单位同一版本重复出现时，若 `op/stratum/value` 文本完全一致即为可重放，
  可出现在任意文件、任意顺序中；版本按数值比较，故 `007` 与 `7` 视作同一版本。
  字段不一致则视为冲突并失败，报错列出两处来源文件与记录号。
- 每个单位取数值最高的版本；最高版本为 `delete` 时移除该单位，即使低版本有 upsert
  也不会复活。低版本数据仍须通过上述校验。层结构不随单位变化，`delete` 不删层。
- 归并结果跨文件、跨记录顺序无关；同一单位在不同版本里可更换层，最终以最高版本为准。

输出只含 `strata` 与 `sample`，不含 `files` 或修订字段：`strata` 按 `id` 文本序、
`sample` 按 `unit_id` 文本序排序，每层保留清单中的 `population`。写盘前调用原输入的
同一校验：单位唯一、层引用存在、每层样本数在 1..population 内、数值合规；
因此不满足抽样口径的归并结果（例如某层删空或样本超过人口）会失败而非发布。
输出可直接作为 `survey-estimate --source`，其报告与等价手工 `survey.json` 一致。

失败（校验、哈希、路径、CSV 结构、冲突、发布）一律退出 2，stderr 指明文件与
可用记录号，既有输出保持不变；成功则经同目录临时文件原子替换写出。
`--output` 必须与清单及任一输入文件不同，且不接受符号链接输出。
样例 `fixtures/revisions/manifest.json` 由 `base.csv`（含一条占位单位 S9）和
`revisions.csv`（S9 在第 2 版被删除、L3 修正为 28）归并，结果与
`fixtures/survey.json` 逐项等价。

## 整数分层配额规划（`survey-allocate`，v1 规划步骤）

`survey-allocate --source <先导样本JSON> --size B --output <配额JSON>` 为下一次
独立分层 SRSWOR 抽样规划整数配额。`--source` 与 `survey-estimate` 同口径，沿用
其全部校验（层结构、unit_id 唯一、每层 1..population 个样本、十进制 value 等）；
先导样本的无偏层内方差 s²h 视为固定规划参数，不随新抽样重估。仅依赖标准库。

- 人口 `Nh=1` 的层无法估计方差，规划配额固定为 0，其 `pilot_variance` 与
  `planned_total_variance` 为 null，不参与预算与方差求和。
- 其余层（`Nh>=2`）先导样本不足 2 个单位时无法估计 s²h，直接拒绝（即使预算
  本身不可行也先报该校验），不把方差猜为 0。
- 每层约束 `min(2,Nh) <= nh <= Nh`（即人口 1 层 0，其余 2..Nh），且 `sum(nh)=B`。
  `B` 必须是 1..100000 的正整数（仅十进制文本，拒绝 0、负数、小数、空白与越界）；
  若 B 落在可行下界 `sum min(2,Nh)` 与上界 `sum Nh（人口1层除外）` 之外则拒绝。

目标是精确最小化预测总体总量方差 `V = sum Nh²(1-nh/Nh)s²h/nh`。记
`Ah = Nh²s²h`，则 `V = sum Ah/nh - sum Ah`，每层关于 nh 离散凸；从 nh 增到
nh+1 的边际收益为 `Ah/(nh(nh+1))`，Ah>0 时随 nh 严格递减。二进制堆每次服务
当前最大边际收益，从下界 2 起逐人分配到上界或预算耗尽，得到全局整数最优：
不枚举任何分配方案，也不在每加一人时扫描全部层（每次堆操作 O(log H)）；
Ah=0 时相邻边际相等（均为 0），堆中允许同层多条零键，过期项惰性跳过。
全部比较使用 Fraction 精确分数，不使用浮点。边际相等时按层 ID 文本序优先服务
靠前的层，因此在所有全局最小解中唯一产生按层 ID 排序后字典序最大的配额向量。

输出顶层含 `budget`、`population`（含人口 1 层的总人口 N）、`planned_sample_size`
（恒等于 budget）、`predicted_variance_total`（即最小 V）、
`predicted_variance_mean`（V/N²）以及按层 ID 文本序排序的 `strata` 数组；每项含
`stratum`、`population`、`pilot_sample_size`、`pilot_variance`、`quota`、
`planned_total_variance`（该层按规划配额的方差贡献 `Ah(Nh-nh)/(Nh nh)`，普查层
与人口 1 层为 0/null）。除整数外所有连续量沿用 numerator/denominator 文本分数，
不输出浮点。结果与输入 JSON 中 strata、sample 的排列顺序无关。

失败（源数据校验、先导样本不足、预算不可行、发布）退出 2 且既有输出逐字节不变；
成功经同目录临时文件原子替换，`--output` 不得与 `--source` 相同且不得为符号链接。
样例 `fixtures/allocate_pilot.json` 含一个单单位层（配额恒 0、方差字段 null）
与三个正方差常规层：B=8 时配额为 noisy=4（普查，贡献 0）、quiet=2、stable=2、
singleton=0，预测总量方差 12、均值方差 12/169；B=12 全部常规层普查，方差为 0。

## 分层抽样实选（`survey-draw`，v1 实选步骤）

`survey-draw --frame <框JSONL> --quotas <配额JSON> --seed <种子> --state <断点库> --output <样本JSON>`
从完整抽样框实际选出单位名单。仅依赖标准库，不联网。

`--frame` 是 UTF-8 JSONL：每行一个 JSON 对象，只允许 `unit_id` 与 `stratum` 两个键，
两者沿用文本约束（非空、<=256 字符、无控制字符）；空白行忽略。`--quotas` 是命令行上的
JSON 对象文本：层 ID（同样沿用文本约束，重复键拒绝）到非负整数配额，总配额 <=100000。
`--seed` 沿用文本约束。未知层、重复单位、坏行（非法 UTF-8/JSON、键集合不符、值越界）
或层人数不足（框内单位数 < 配额）一律拒绝；配额为 0 的层合法且不产出单位。

各层内按 `SHA256(UTF-8(seed + 空字符 + unit_id))` 升序排序，哈希并列按 unit_id 文本序，
取前 quota 个单位。输出顶层只有 `sample` 数组，每项仅含 `unit_id`、`stratum` 两个字段，
按 unit_id 文本序排序；结果不依赖框内行序（换序同一命令产出逐字节一致）。

框按行流式处理：全框与全部 unit_id 都不进入内存，解析出的单位随批写入 `--state`
SQLite 断点库（unit_id 主键即查重），每 10000 行提交一批；处理千万行框时进程峰值内存
<=64 MiB。断点库绑定框原始字节 SHA-256、规范化后的配额与 seed：续跑时先校验绑定，
不符即拒绝且不改动库内容。强杀后以同一命令续跑：已提交批次按原始字节 SHA-256 逐批
核验（只哈希、不重解析），从已提交记录之后继续解析；解析或约束失败回滚当前批，已提交
批次不受影响。全部校验通过后才物化样本并原子发布（同目录临时文件 + 替换），退出 2 时
既有输出逐字节不变；发布前后强杀，重跑都得到相同文件。断点库以排他文件锁保护，禁止
并发运行；`--frame`、`--state`、`--output` 两两不得相同，`--output` 不得为符号链接。

样例 `fixtures/frame.jsonl` 含 alpha/beta/gamma 三层共 12 个单位；配额
`{"alpha":2,"beta":2,"gamma":1}`、seed `demo-1` 时选出 A1、A4、B3、B4、G1。
